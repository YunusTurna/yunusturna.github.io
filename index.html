📱 App Projects

SelfSporTrack is a comprehensive fitness tracking app built with Flutter. It features workout logging, customizable workout programs, meal planning with calorie tracking, weight and body measurement history with chart visualizations, water intake tracking, and a calendar overview with local data storage and dark mode support.

Smart Dog Collar is our capstone/graduation IoT project. The hardware side uses an ESP32 microcontroller paired with an MPU6050 accelerometer/gyroscope for motion and activity detection, and a NEO-6M GPS module for real-time location tracking. The Flutter companion app connects to the collar via Bluetooth Low Energy (BLE), displaying live GPS data on an interactive map, logging walking sessions with distance and duration stats, monitoring activity levels with chart visualizations, and managing dog profiles — all backed by Firebase authentication and cloud storage.
