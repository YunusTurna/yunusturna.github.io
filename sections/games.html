📱 Mobile Apps

SelfSporTrack

  • Developed a cross-platform fitness tracking app using Flutter.
  • Features digital workout logging with customizable programs.
  • Includes weight history tracking, meal planning, and water intake logs.
  • Provides local storage support and a toggleable dark mode.

Smart Dog Collar

  • Capstone IoT graduation project containing hardware and mobile application parts.
  • Uses ESP32, MPU6050 (accelerometer/gyroscope), and NEO-6M GPS modules.
  • Flutter app connects via Bluetooth Low Energy (BLE) to stream active location metrics.
  • Features session logging, activity graph visualizations, and Firebase cloud database sync.
